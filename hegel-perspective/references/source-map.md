# 出处地图：作品、版本、可回查位置

这是入口地图，不是“这些书全部读过”的宣言。核读范围见六维报告和证据台账。**ID是本Skill索引，不是学术出版物编号**；下列一行可以含一部作品的多种载体，不能将行数、页面数、语言数相加当独立来源数。

## 一、引用约定

- **PhG**：《精神现象学》，以通行¶号辅助定位；旧德文电子本不全显示这些号，须用章名和原文短句核对。
- **WdL**：《逻辑学》（大逻辑）。以存在论/本质论/概念论及篇—章—节定位，不将Marxists网页的英译页号/段号当原版节号。
- **EL / EN / ES**：《百科》1830版的逻辑学/自然哲学/精神哲学。三部分共用§号，不能把早版编号套进1830。
- **PR**：《法哲学原理》，1820实际出版、扉页1821；§、Anmerkung（作者附注）与Zusatz（后加补充）分别标明。
- **A**作者生前亲定刊行正文/作者附注；**B**书信/作者遗稿；**C**学生记录与编辑补充；**D**后世研究。1832存在论是生前修订、身后刊行的特殊A类情况。翻译与转录仍有自己的中介层。

## 四、本地查找

`manifest.json`保留每次主采集的请求URL、重定向URL、原始路径、TXT路径、字节数、SHA-256与HTML锚点。`corpus.py`以ID检索，示例：

```text
python scripts/corpus.py show right__prstate --find "§ 260"
python scripts/corpus.py show logic2-de --find "List" --context 1200
python scripts/corpus.py find "§ 249" --id zeno-enc
```

辅助研究者的独立索引分别在`letters-agent/source-index.json`、`critics-agent/source-index.json`；表达样本在`research/voice-samples.json`。同一著作的两种语言、镜像、HTML/TXT/PDF不增加独立来源数。

政治制度题的直接入口：PR§273三权、§§279–281君主与继承、§301等级及§§308、311代表/选举，英译均在`right__prstate1`；德文用`zeno-pr__*`检索节号。不要仅凭§260的自由原则推出现代普选立场。
