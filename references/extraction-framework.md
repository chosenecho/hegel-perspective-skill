# 心智模型提取框架

## 三重验证方法论

对每个候选论点，逐个通过以下三道验证。全部通过 → 心智模型；仅通过1-2道 → 降级为决策启发式；0道 → 丢弃。

### 验证1：跨域复现（Cross-Domain Recurrence）

该观点是否在≥2个不同领域/话题中反复出现？

- 在著作中谈哲学时提过 + 在书信中谈艺术时也提过 → 通过
- 只在讨论某个具体话题时出现 → 不通过
- 仅在他人评价中出现，本人从未明确表达 → 不通过

**操作**：扫描01-05的所有调研文件，记录该观点出现的场景数。≥2个不同话题域 = 通过。

### 验证2：生成力（Generative Power）

能否基于该观点推断此人对于新问题的立场？

- "如果黑格尔面对AI时代的主奴辩证法，他会怎么看？" → 能基于其辩证法框架做出合理推断 → 通过
- 该观点只是一个具体事实判断，无法外推 → 不通过

**操作**：构造3个此人从未讨论过的新场景，尝试用该观点推断其可能立场。如果3个场景中有≥2个能产出合理推断 → 通过。

### 验证3：排他性（Exclusivity）

这个观点是否足够独特，不是「所有聪明人都这样想」的通用道理？

- "应该独立思考" → 通用道理，几乎所有人都会说 → 不通过
- "主人依赖于奴隶的承认才能确证自我意识" → 高度独特 → 通过

**操作**：判断该观点是否可归属于其他3个以上思想家。如果≥3个其他思想家也持类似观点 → 不通过。

## 心智模型记录格式

```markdown
### 心智模型N：[名称]

**一句话描述**：[20字以内]

**来源证据**：
- 场景1：[具体出处]，涉及领域：[X]
- 场景2：[具体出处]，涉及领域：[Y]

**应用方式**：面对[类型问题]时，可以[如何使用该模型]

**局限性**：该模型在[什么条件下]会失效，不能用于[什么场景]

**排他性评分**：高/中/低
```

## 质量自检清单

构建SKILL.md完成后，逐项检查：

| # | 检查项 | 通过标准 | 不通过信号 |
|---|--------|---------|-----------|
| 1 | 心智模型数量 | 3-7个，每个有≥2个来源证据 | <3或>10 |
| 2 | 每个模型的局限性 | 明确写出失效条件 | 只写优点不写局限 |
| 3 | 表达DNA辨识度 | 读100字能认出是谁 | 像通用ChatGPT |
| 4 | 诚实边界 | 至少3条具体局限 | 只有「不能替代本人」这一条 |
| 5 | 内在张力 | 至少2对矛盾/张力 | 观点高度一致（太假，真人都有矛盾） |
| 6 | 一手来源占比 | >50% | 主要依赖二手转述 |

不通过的项需回到Phase 2修复，最多迭代2轮。
